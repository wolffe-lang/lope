# The matcher

lope's matcher is written from first principles (ruling #91 R3): no source
of nucleo, fzf, skim, zoxide, autojump, z or fasd was read. gump's
`src/matcher/fuzzy.rs` was read for its interface only (`score`, `rank`,
the `Match` fields, the doc comments, the tests' assertions), never a
function body. Every constant below was fixed by asking the gump binary at
`gump.pin`: `gump query -a -s` prints a combined score, and for a store of
one path at frecency 0 that score is the match score itself. The rows
that fixed them are `tests/oracle/probes.jsonl` (322, all equal); the
source is `src/matcher/`.

## A query

The command line's words are **terms**. A term is split into **atoms** at
each space not escaped by a backslash (`a\ b` is one atom holding a
space); a tab, a non-breaking space or any other character is part of an
atom. There is no pattern syntax: `^`, `$`, `'` and `!` are characters to
match like any other. Matching ignores case; an atom made only of ASCII
also reads a Latin letter with diacritics as its base letter ("Folding").

A path matches when every atom of every term occurs in it as a
subsequence. Its **score** is the sum over the atoms of each atom's best
alignment score (below), then:

1. **Order.** With two or more terms, each term's first character is
   looked for in the lowered path, each after the position where the
   previous one was found (the first from the start). If one is not
   found, the score is quartered (integer division). Only first
   characters are looked at: `app proj` on `…/projects/myapp` is in
   order, since a `p` follows the `a` of `app`.
2. **The last component.** When every atom of the LAST term occurs in
   the path's last component (as Rust's `Path::file_name` reads it), the
   score gains 100, and 50 more when the last term, lowered, IS that
   component. An empty last term occurs everywhere (100).

The **combined score** weighs the score by frecency `f`:

    combined = score × (1 + min(f, 40) / 160)

lope keeps it exactly, as `score × (640,000,000 + min(fq, 160,000,000))`
with frecency in quarter-millionths (`matcher.key_of`); printed with
`query -s` it is divided back and rounded to two decimals.

## The recurrence

For one atom `a[0..m)` against a text `t[0..n)` (code points; for an ASCII
atom the folded text), with `B[j]` the bonus of position `j` (next
section):

- The first atom character matched at `j` scores `16 + 2·B[j]`; its
  **run** value is `B[j]`.
- Atom character `i > 0` matched at `j`, right after character `i − 1`
  matched at `j − 1` (consecutive): `S + 16 + max(r, B[j], 4)`, where `S`
  is the best score ending at `(i − 1, j − 1)` with run value `r`; the new
  run value is `max(r, B[j])` when `B[j] ≥ 8`, else `r`.
- Atom character `i > 0` matched at `j` after a gap, the previous one at
  `j' ≤ j − 2` (`k = j − j' − 1` positions skipped):
  `max(0, S' − (k + 2)) + 16 + B[j]`, where `S'` is the best score ending
  at `(i − 1, j')`; the run value is `B[j]`. The gap's penalty is 3 for
  the first skipped position and 1 for each further one, and what came
  before is never carried below zero (Smith-Waterman's floor:
  `ab` across a gap of 40 scores 16, the `b` alone).
- The atom's score is the best over every alignment of every character.

The state is (atom position, text position, run value), and the run takes
only the values 0 (or anything under the floor of 4), 5, 8, 9 and 10, so
the programme is `m × n × 5` cells, two rows kept (`matcher/fuzzy.lu`).
Before any of it, a pass over the path's bytes asks whether each ASCII
atom occurs at all; most of a store is passed over there.

## Classes and bonuses

A code point's class: **white** (a space and the other blanks), a
**delimiter** (`/ : , ; |`), **nonword** (any other ASCII punctuation or
symbol, and non-ASCII punctuation), **lower**, **upper**, **digit**. The
text's start reads as white before it.

The bonus `B[j]` of a match at `j`, by the class of `t[j]` and of
`t[j − 1]`:

| matched | before it | bonus | probe |
|---|---|---|---|
| white | any | 10 | `a\ b` on `/a b`: 186 |
| delimiter | any | 0 | `/` on `/xab/cd`: 16 |
| nonword | any | 8 | `-` on `/xab-cd`: 132 |
| a letter or digit | white, or the start | 10 | `a` on `app`: 136 |
| a letter or digit | delimiter | 9 | `u` on `/home/u/projects`: 34 |
| a letter or digit | nonword | 8 | `app` on `/home/u/my-app`: 180 |
| upper | lower | 5 | `app` on `/home/u/myApp`: 168 |
| digit | a letter | 5 | `2` on `/x/app2`: 126 |
| anything else | | 0 | `app` on `/home/u/x9app`: 156 |

## Folding

An ASCII atom compares against the text lowered and folded: a Latin letter
whose Unicode name is `LATIN SMALL|CAPITAL LETTER X WITH …` reads as `x`
(`src/matcher/fold.lu`, generated by `tools/gen-fold` from the names). An
atom holding a non-ASCII character compares against the text lowered only,
so `é` does not match `e` while `e` matches `é`. Lower case is the simple
mapping for ASCII, Latin-1, Latin Extended-A, Greek and Cyrillic; `İ`
(U+0130) folds to `i` but lowers to itself, since its full lower case is
two code points and equals no one-letter term.

gump folds differently: `tools/fold-check` (896 code points) finds 508 that
agree. lope folds every Latin capital with a diacritic (gump folds Latin-1's
and two others); gump folds `ß`, `ı`, `ſ` and some turned and open letters,
which carry no diacritic; and in Latin Extended Additional gump answers
other letters (`ḁ` as `c`, `ḃ` as `e`), where lope answers the base letter.

## Ties

gump keeps its store in a hash map and sorts with a stable sort, so equal
combined scores come back in a different order on every run: 164 of the
corpus's 654 cases have a shared best. A shared best is common because
frecency counts only up to 40: every often-visited directory weighs the
same. lope breaks a tie by the uncapped frecency, then the shorter path,
then byte order, so its answer is always one of gump's possible ones and
always the same. In the working directory's step (`query --cwd`) every
name has frecency 1 and ties keep the order the directory lists them in,
which is what gump's stable sort keeps too.

## How agreement is measured

`tools/oracle-check` replays `tests/oracle/corpus.jsonl`, 654 cases
recorded from gump (`tools/oracle-record`, three answers per case and the
full ranking, from which the tie set): lope agrees when it lands where gump
did, or anywhere in gump's tie set. The floor (`tests/oracle/FLOOR`) is the
first measurement, 100%, and is never lowered.
